# Memory map

| Base                       | Description   |
|----------------------------|---------------|
| `0x00000000 - 0x00FFFFFF` | Flash         |
| `0x01000000 - 0x017FFFFF` | RAM A         |
| `0x01800000 - 0x01FFFFFF` | RAM B         |
| `0x02000000 - 0x02000003` | Clock          |
| `0x02000004 - 0x02000007` | Input         |
| `0x02000008 - 0x0200000F` | Video         |
| `0x02000010 - 0x02000013` | Audio         |
| `0x02000014 - 0x02000017` | UART          |
